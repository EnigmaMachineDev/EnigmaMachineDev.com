FretboardTools

A bass fretboard voicing engine in your browser. Give it a tuning, how many strings the chord uses, a fret window, and the scale degrees you want — it enumerates every fingering that fits, rates each one for playability with a real finger-assignment solver, and groups them so the comfortable voicings rise to the top. No account, no backend, no API keys.

Features

What FretboardTools does

🎸

Every Voicing, Enumerated

Set the parameters — tuning, string count, fret window, whether string skips are allowed, which degrees you want — and every fingering that satisfies them comes back. Not a lookup table of the usual shapes.

🖐️

Rated for Real Hands

A genuine finger-assignment solver, not a rule of thumb. It enforces finger order and barre legality to tell you what's comfortable, what's a stretch, and what's simply impossible — and you choose how much difficulty to see.

↔️

Shapes, Not Positions

Results are fingerings, normalized so they're slidable anywhere on the neck. Learn a shape once and it works at every root — names, degrees, and pitches are worked out from wherever you put it.

🔗

Every Search Is a Link

Your query lives in the URL, so any set of results is a shareable, bookmarkable link. Send someone the exact voicings you're looking at — no account, no saved-state handoff.

🔍

Identify & Scales

Click notes onto a fretboard and get the chord read back as ranked interpretations, ambiguity included. Or browse scale box coverings to see where a degree set sits on the neck.

🔒

Yours & Private

Runs entirely in your browser — it makes no network requests at all. Your tunings, chord definitions, and favorites stay in local storage and export to a single file that the Ambitus Android app reads too.
