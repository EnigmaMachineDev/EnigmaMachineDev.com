Android · Project Progress Tracker

Wright

Track hands-on and creative projects from first step to finished piece. Define reusable project types as an ordered set of stages and sub-steps, then start a project that gets its own independent copy — editing a build never touches the template, and vice versa. Attach progress photos, set per-step wait reminders and a target date, and let completion roll up from steps to stages to the whole project on its own.

Features

What Wright does

📐

Reusable Blueprints

Define a project type once as ordered stages and sub-steps — a build sheet you'll reach for again. Woodworking, painting, brewing, instrument repair: whatever you make more than once.

📋

Independent Copies

Starting a project deep-copies its type into a snapshot of its own. Tweak a stage on one build and the template — and every other build — stays exactly as it was.

📊

Progress That Adds Up

Check off a sub-step and progress rolls up automatically — sub-step to stage to project — with the current stage highlighted and a nudge when a build hits 100%.

📷

Progress Photos

Attach photos to a project's stages, steps, and log to document how a build came together. Images are compressed and kept on your device, in the app's private folder.

⏰

Waits & Reminders

Give a step a wait period — glue curing, paint drying, a fermentation rest — or a project a target date, and get a local reminder when the wait is up. Everything fires on-device.

🔒

Yours & Private

Everything stays on your device — no account, no network, no tracking. Export a single-file backup (photos optional) to move or restore all your project types and builds.
